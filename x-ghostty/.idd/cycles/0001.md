## 人間への問い
3 つの検証ゲート(C88〜C90)が、macOS 27 / Xcode 27 への更新に伴う環境要因で通りません。次の 2 点を用意してから `idd resume` してください。
1. **Metal Toolchain の導入**: `xcodebuild -downloadComponent MetalToolchain` を実行してください(ネットワークからの取得とシステムへの導入を伴うため、周回からは行っていません)。導入後は `xcodebuild -showComponent MetalToolchain` が installed になります。
2. **zig 0.15.2 と MacOSX27 SDK の不整合(libcxx の `INFINITY` 未定義)への対処**。どれを選ぶか決めてください。
   - (a) 推奨: zig がビルドに使う SDK を 26.x に固定する。例として Xcode 26 を併存させて `DEVELOPER_DIR` で選ぶ、あるいは MacOSX26.2 SDK を Xcode 27 の SDK として参照させる方法がある。CLT の SDK 26.2 では当該エラーが出ないことは確認済み。
   - (b) リポジトリ側で回避する。ビルド設定で `INFINITY` を補う等の方法になる。この場合は上流由来のビルド系に手を入れることになるため、承認が要る。
   - (c) 上流修正を含む zig 0.15.x の新しいパッチ版が出ていれば、それへ更新する。
   これが決まらないと `zig build` が通らず、`just swift-test` の前提となる xcframework も作れません。その結果、全条件の検証が止まります。
